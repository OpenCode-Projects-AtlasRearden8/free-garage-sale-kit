Simple ways to use Lot #

  • Quick way (no math): count up from 1 as things sell — "1, 2, 3…" — and erase the count when the day's done
  • Resaler way: Lot # = sale date + table letter + row — e.g. 0-5-1-2-8 / K / 3 means Oct 5, Kitchen table, third row
  • Batch way: group $1 items into one lot (Lot #0-5-1-2-8/B / 24 pieces) instead of one line per item

Folding it into resale-lot records
